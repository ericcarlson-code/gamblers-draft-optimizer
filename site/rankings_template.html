League Scores

Real weekly matchup scores for this specific league — either synced from Yahoo (pending API access approval) or entered by hand week to week. Yahoo's own scoring sometimes comes out slightly different from this league's actual rules, so the plan is to pull the underlying raw stats and score them ourselves here, not just copy Yahoo's number. This is also the foundation for a future dollar-edge view: which decisions carried the most expected value under this league's payout math, not a payout tracker itself.

Points and VOR reflect the league's current custom scoring config at time of generation. Tier = statistically significant value drop-off within a position (lower is better). In the Trend column, the solid line is actual results (2020–2025); the dashed segment and hollow dot are the 2026 projection, not an observed result. Mock Draft, Trade Calculator, and Stack Rankings all run entirely in your browser from the 2026 Projections dataset — nothing is sent anywhere. This is a static snapshot; open the live app for real-time draft tracking against your actual draft.
